# Donkey Kong

A Donkey Kong-style arcade platformer in a single HTML file: no libraries, no image or audio files.

**▶ Play it: https://jonclegg.github.io/donkey-kong/**

## Controls
| Key | Action |
| --- | --- |
| Arrows / WASD | Move, climb ladders |
| Space / Z | Jump |
| Enter | Start |

## Run locally
Download `index.html` and open it in any modern browser.
